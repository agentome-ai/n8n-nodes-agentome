# Changelog

## 0.1.0

- The Agentome node: create a task and wait for its result, get a task or a run, comment on a
  task and ask for changes, run a task again, cancel a run, list waiting approvals, approve, deny
  and answer them. Usable as a tool by n8n's AI agents.
- The Agentome Trigger: a run ended, or an approval waits.
